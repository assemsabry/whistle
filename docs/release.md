# Release Process

1. Run the complete test suite.
2. Run inference smoke tests on representative licensed samples.
3. Review data and dependency licenses.
4. Generate checksums and a model card.
5. Tag the source repository with a version.
6. Upload only validated model weights to Hugging Face.
7. Publish release notes with metrics, limitations, and provenance.

GitHub is the source of truth for code and documentation. Hugging Face is the source of truth for released weights and the minimal model card.

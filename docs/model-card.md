# Whistle Model Card

## Model

Whistle is an open-source football video analysis system developed and trained by Assem Sabry. Released weights are hosted at [assemsabry/whistle](https://huggingface.co/assemsabry/whistle).

## Intended use

Anonymous match analysis, detection, tracking, pitch calibration, ball state estimation, and basic event timelines.

## Out of scope

Player identification, names, positions, jersey numbers, identity linking, and player ratings.

## Limitations

Performance depends on camera angle, resolution, occlusion, lighting, motion blur, field visibility, and the license-compatible training data available for a release.
